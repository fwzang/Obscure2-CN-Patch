## 🎮 项目简介

本仓库包含《恶夜杀机 2》（Obscure II）简体中文汉化补丁的 **核心源码、构建脚本与文本翻译资源**。
游戏本体属于 Ubisoft / Hydravision 所有。本补丁完全免费，严禁用于商业倒卖。

## ✨ 核心特性与技术亮点

1. **史诗级排雷：N 卡贴图与电击枪修复**
   - 针对 NVIDIA 显卡底层驱动导致的“浴室贴图消失”和“电击枪卡死”问题，本项目内置了微软 `D3D9On12` 兼容层。
   - 代理 DLL 会根据显卡厂商（`VendorId`）**自动分流**：N 卡自动启用 On12 转译，A 卡/Intel 保持原生 D3D9 渲染。
2. **像素级字体匹配**
   - 放弃粗糙黑体，选用 **思源宋体 Bold (Noto Serif TC)**，经过高分辨率超采样与墨迹填充率比对，与原版日文字体完美融合。
3. **彻底消灭切屏死锁**
   - 引擎重构为无边框窗口化逻辑，彻底解决老游戏 Alt-Tab 切屏无响应的顽疾。
4. **100% 完整汉化**
   - 剧情、UI、物品说明全量注入，断行完美适配 UI 面板，保留原汁原味的粗口语气。

## ⚠️ 已知限制

- **Steam 覆盖层失效**：因 N 卡走了 D3D9On12 转译，会导致 Steam 游戏内覆盖层（截图、Shift+Tab）失效。若需恢复，请修改游戏目录下的 `o2_mode.txt`，将 `auto` 改为 `compat`（代价是贴图缺失问题重新出现）。
- **启动瞬闪**：游戏刚启动的 1 秒内，画面可能闪过图集样式，属引擎加载时序问题，不影响游玩。

## 🛠️ 源码编译指南

如果你希望自己编译 DLL，请阅读 `03_文档/` 目录下的说明。
- **编译禁令**：必须使用 `-DFORCE_POINT_SAMPLER=0` 且禁用自动 ImageBase（`--image-base`）。
- 核心 Hook 源码位于 `05_hook源码与译文/d3d9_proxy.c`。
