## v74 探针会打印什么

```
[V73] UP stage0tex=0F8231E0 512x256          ← 这一笔 stage0 绑的是哪张纹理
[V73] UP pt=5 primCount=2 stride=36 nVert=6   ← 类型/顶点数/步长
[V73] UP v0:  12.34  1182.00  …              ← 每顶点坐标（定点数，每顶点一行）
```

四条路径都会打（DIP / DP / UP / DIPUP）。拿到后判断：
1. 贴图由**哪条路径**画（UP 最可能）；
2. 那一笔绑的 stage0 是**原版贴图**还是**中文图集**（后者=误替换，方向完全不同）；
3. y 到底多大（是否 > 窗口高）；
4. **若一条 `[V73]` 都没有** → 它不经过这四个 D3D9 绘制函数，得改查引擎/资源。

## 安全保证

v74 = v1.03.3 第一版**去掉自适应** + 阈值 9 + **纯只读探针**：
- 不写任何顶点、不重画、不跳过绘制（v70~v72 的重画逻辑已全部移除）；
- Lock/Unlock 严格成对；读失败即跳过打印；
- 坐标一律定点数（`wsprintfA` 不支持 `%f`，用了会被打成 `f` 并截断后续格式）。
