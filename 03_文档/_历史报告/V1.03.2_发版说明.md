## 二、本版内容

1. **中文全文本**：3,844 条文本全部汉化（含开场、物品、提示、结局）。
2. **中文界面字体**：两套方案可选 —— 方案 B 寒蝉活楷（4× 超采样，观感同 V1.00）、
   方案 A 寒蝉端黑体 Bold（笔画更重，拉伸后更清晰）。
3. **启动即中文、无闪现**：字体图集在 stage0 首次绑定即被识别并替换，不再出现启动瞬间的乱码闪烁。
4. **贴图不再被误替换**：只有确认过的字体图集会被换成中文字集，同规格的 UI / 场景贴图原样保留
   （V1.03.1 引入绑定次数提升，V1.03.2 收紧到只认 stage0）。
5. **Alt+Tab 切屏不卡死**：强制无边框窗口化，避开全屏独占下 Present 无限阻塞。
6. **可选宽屏补丁**（ThirteenAG Widescreen Fix）。

## 三、已知限制（重要，请务必阅读）

> **【N 卡（NVIDIA）部分显卡在 2560×1440 及以上分辨率下，个别场景（如浴室）的
> 提示贴图不显示。建议以 1920×1080 游玩。】**

- **这是原版引擎自身的问题，不是汉化补丁造成的。** 已做的对照实验：
  - 同一台机器上，**AMD 显卡原生**能显示该贴图，**NVIDIA 显卡原生**不显示；
  - 换成 **DXVK（Vulkan 转译层）** 接管 N 卡后，**仍然不显示** → 说明不是 N 卡 DX9 驱动
    的特有路径，而是引擎在高分辨率下的 UI 坐标/裁剪问题（N 卡路径上被裁掉）。
  - 引擎的 UI 布局死绑视口尺寸（视口 2048×2048 > 窗口高 1440），底部约 30% 的 UI
    落到可视区外；A 卡路径对该情况容错，N 卡路径严格裁剪。
- **1080p 下该贴图正常显示**，其余内容不受影响。
- 想彻底解决需引擎侧修复（社区有 dgVoodoo2「Fast video memory access」的反馈，
  但尚未在本机复现验证），本补丁不冒险改动渲染管线。

## 四、安装与使用

1. 运行 `Obscure2_汉化补丁_V1.03.2.exe`，选择字体方案（默认 B），
   建议勾选「安装前备份原文件」与「同时安装宽屏补丁」；
2. 安装前需保证 `datapack.hvp` 为**原版**（若装过其它汉化，先用 Steam
   「验证游戏文件完整性」还原，或用本包「还原原版」按钮）；
3. 差分安装会读取你的原版包重建中文包，约 5–20 秒。
