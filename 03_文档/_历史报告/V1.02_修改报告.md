## 一、本版解决的三件事

### 1. Alt+Tab 切屏卡死（致命问题，本版核心）

**现象**：多次切屏后画面静止，鼠标键盘有响应、后台进程仍在运行，但桌面被占住、任何程序都打不开。

**排查过程**（全部有日志实证）：

| 步骤                          | 结论                                      |
| --------------------------- | --------------------------------------- |
| 加入看门狗线程，每 1.5 秒记录当前执行位置     | 卡在 `PRESENT:2-callOrig`，帧号完全冻结          |
| 查 `TestCooperativeLevel`    | 全程返回健康，`[GUARD]` 计数始终为 0 —— **设备并没有丢失** |
| 对照实验：移除代理 d3d9.dll 用系统 d3d9 | 不卡 —— 问题在汉化 DLL 参与后的呈现路径                |

**根因**：游戏以全屏独占（`Windowed=FALSE`）运行。Alt+Tab 让出独占显示模式后，  
引擎既不处理 `WM_ACTIVATE`、也不调用 `Reset` 重新获取模式，于是 `Present` 在等待  
一个永远不会到来的 vblank，无限阻塞。

**修法**：`CreateDevice` 之前把 `D3DPRESENT_PARAMETERS` 改成窗口化  
（`Windowed=TRUE`、`FullScreen_RefreshRateInHz=0`），创建成功后把窗口改为  
`WS_POPUP` 无边框并铺满屏幕。分辨率、画面比例完全不变，但没有独占显示模式，  
`Present` 不再等待 vblank。

### 2. 切屏后窗口永远置顶

**根因**：游戏认为自己仍在全屏，会给自己加 `WS_EX_TOPMOST`；同时 `WS_POPUP`  
窗口没有 `WS_EX_APPWINDOW`，不参与 Alt+Tab 列表。

**修法**：创建时设 `WS_EX_APPWINDOW`、清 `WS_EX_TOPMOST`/`WS_EX_TOOLWINDOW`，  
`SetWindowPos(HWND_NOTOPMOST)`；之后仅在窗口失焦时复查并清除 TOPMOST  
（避免与游戏抢 z-order 造成闪烁）。

### 3. 高分辨率（2K）下 3D 提示面片越界

**现象**：浴室等场景的悬浮提示贴图在 2560×1440 下飞出屏幕、不显示；1080p 正常。

**修法**：窗口化重置渲染路径后，该问题在 2K 下已恢复正常。同时内置了通用  
「小面片越界纠正」（`O2_FIX_UI_ANY`，默认开启但惰性：视口 ≤1080 直接放行，  
仅在 >1080 且 `maxY` 超出视口时才临时缩放投影矩阵，画完立即还原）。

## 二、稳定性加固（与上述修复配套）

| 加固项    | 说明                                                     |
| ------ | ------------------------------------------------------ |
| 设备丢失守卫 | 每次碰纹理/矩阵前实时 `TestCooperativeLevel`，不健康直接透传             |
| 悬空指针清理 | 丢失/恢复跳变时作废 `g_bigSrc` 等裸指针（它们没有 AddRef，设备一丢就悬空）        |
| 看门狗    | 后台线程每 1.5s 写 `[WD] ckpt=... f=...`，卡死时最后一条即卡点          |
| 帧末还原关闭 | `PRESENT_RESTORE=0`，Present 前不再做 `SetTexture`，减少呈现路径干预 |

## 五、已知限制

1. **字体判据仍是「512×256 + A8R8G8B8」**。游戏的同类规格纹理不止字体，  
   极小概率会有非字体纹理被替换成中文图集。遇到疑似情况可用 `O2_NO_SWAP=1`  
   启动确诊（中文会花，属预期）。
2. **启动偶发 `0xC0000005`（约 2/3 次）**，发生在 `ckpt=init`、设备创建之前，  
   疑似 Steam overlay（`gameoverlayrenderer.dll`）注入竞态，与本补丁逻辑无关，  
   重开即可。
3. **不再使用全屏独占**。画面为无边框窗口铺满屏幕，分辨率与比例不变；  
   若需恢复独占，设 `O2_WIN=0`（会重新出现切屏卡死，仅供对照）。
