## 三、本次修复的两处问题

### ① 包内「方案B 图集」歧义（已标注）
- `06_独有资产/方案B_字体产物/g3_atlas.png` = `c1794fa2`（活楷 **Lanczos SSAA4**），
  **从未投产**；出厂在用的是 `e172a188`（活楷 **BOX SSAA3**），在 `04_基线与回滚/`，
  并原样内嵌在方案B 的 d3d9.dll 里。
- 处置：**不擅自替换用户资产**，改为在同目录新增 `图集说明.md` 写清三张图集的角色与投产状态。

### ② 手动安装版缺件（已补齐）
此前 `01_安装包/手动安装版/` 只有 DLL 与 delta，**没有安装/还原脚本**（清理时丢失），无法独立使用。已补：
- `apply_delta.py` — 差分重建器（与图形安装器同一套 op 逻辑；先校验原版包 size+crc，
  不匹配即拒绝并提示先还原原版；自动备份 `datapack.hvp.o2bak`；重建后校验 size/crc 再原子替换）
- `install.bat`（方案B）/ `方案A_寒蝉端黑体/install_A.bat`（方案A）— 纯 ASCII + CRLF
- `restore.bat`（两套通用）— 只删 md5 命中我们自家 DLL 的 `d3d9.dll`；备份非原版则拒绝还原
- 方案A 目录补入 `datapack_a.delta` + `apply_delta.py`

## 四、装机后的自检（三条命令）

```bat
:: 1) 代理指纹
certutil -hashfile <游戏目录>\d3d9.dll MD5
::    方案B = ea685f67d9e3ec36e9d6326ec31b910e
::    方案A = ea45b921c8399fe864e5062169baa9a3
:: 2) 数据包指纹
certutil -hashfile <游戏目录>\datapack.hvp MD5
::    方案B = d25123d226ebd1dfae39c053717db808
::    方案A = e657e90dcfe225da3af5b19e394f5622
:: 3) 代理版本标记
findstr /C:"V70_PROD" <游戏目录>\d3d9proxy.log
```

> 方案与数据包**必须同选**（A↔fullA、B↔full18）；混装会导致字形几何与图集不匹配而错位。
