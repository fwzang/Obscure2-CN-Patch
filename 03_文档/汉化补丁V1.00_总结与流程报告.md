## 二、整体技术流程

```
① 数据层解析
   hvp 容器 → 解包出 1,240 个文件
   ├ 贴图 216 张（126 BMP 24bit + 90 TGA 32bit）
   ├ 字体定义 def（Font_Nonserif12）
   └ 5 个语言文本容器（en/de/es/fr/it）→ 3,844 条记录
        ↓
② 文本层：翻译 + 断行
   ├ 译文注入 5 个语言容器
   ├ 断行宽度按 UI 部件分别定：
   │   对话框 470px / 角色简介 358px / 物品描述按各条英文最宽行
   └ 规则：英文单词不拆、优先标点断、避头尾、保留 %s 与 <PS2_*> 标签
        ↓
③ 字体层：字形表 + 图集
   ├ def 字形记录（字符码 → 格子坐标，盒 19×25，基线 20）
   ├ 图集 2048×1024，SSAA3 + BOX 缩放，无描边无二值化
   └ 三处尺寸必须同步：gate3_atlas.py / d3d9_proxy.c 的 ATLAS_W/H / 重新生成的 def
        ↓
④ 渲染层：D3D9 代理
   ├ Hook_CreateTexture / UpdateTexture：登记 512×256/fmt21 纹理
   ├ Hook_SetTexture：把字体纹理换成大图集
   ├ Hook_DrawIndexedPrimitive：3D 绘制前还原 stage0
   └ Hook_Present：帧末还原 + Reset 时解绑（防 INVALIDCALL 闪退）
        ↓
⑤ 打包层
   ta2_write.py 注入 → obscure-hvp create → verify_pack.py 一致性关卡
        ↓
⑥ 发布层
   原生 Win32 安装器（载荷追加 + 尾部清单）→ 单文件 EXE
```

## 三、核心技术决策链（含被证伪的路线）

这一节记录**走过的弯路**，避免后来者重蹈。

### 3.1 漏图的真正根因：登记表命中"旧指针"

游戏会反复销毁/重建字体纹理，**旧地址被新纹理复用**。原先的判据只认"这个地址曾经登记为字体"，
于是把书架、木门、光照贴图、UI 面板统统换成了中文图集。

**证据链**：
- 导出全部 512×256 纹理 → 发现 4 张像素完全相同（同一张拉丁字库的 4 个实例）
- 但换绑分支（只认 512×256）却导出了 512×512、256×256 的图 → 指针复用

**修法**（v45）：命中登记表后，**直接问 D3D 这个对象现在多大**。
> ⚠️ 必须绕过本地缓存（`tex_desc` 带指针缓存，会读到"过去的 512×256"，校验形同虚设 —— v44 就栽在这）。
> 新增 `tex_desc_direct()` 专用于此判定。

### 3.2 被证伪的路线（都不再采用）

| 路线 | 失败原因 |
|---|---|
| FVF(XYZRHW) 判 2D/3D | 本引擎是软 T&L，3D 顶点也是 XYZRHW → 恒真 |
| ZENABLE 判 2D/3D | 菜单里 Z 也开 → 文字被误还原 |
| 顶点数阈值 | 文字与几何都是小批量 |
| 帧末还原 stage0 | 还原成字体 → 墙面出现字库图案 |
| DIP 前还原成 prev0 / last3D0 / beforeSwap / NULL | 都不是"被替换的那一张"→ 黑条 / 平光 / 木纹 |
| 在 UpdateTexture 里算内容哈希找字体 | **字体根本不走 UT**（39,000 帧里只有 4 次 512×256 UT）|
| 回到 512×256 原生图集原地覆盖 | 512×256 装不下 2,148 个汉字（缺口 8.9 倍）|

### 3.3 关键教训

1. **"事后猜材质"在多 pass 引擎里是死路**——信息不足，正确做法是从源头不替换错的对象。
2. **改宽字符串必须三件事同时做**：写内容、**写 NUL**、确认不越过原串长度。
   （v46 漏写 NUL → 菜单显示"成就hievements"）
3. **面板宽度不是统一值**：对话框 470、角色简介 358、物品描述更窄。
   目标宽度应取**该条英文的最宽行**——英文是设计师按各自面板手工折行的。
4. **重排必须"先合并段落再装行"**，只对超宽行重排等于什么都没做。
5. **数组大小与上限必须同源**（v31 写 `NEWF_MAX 64` 但数组只有 32 → 越界写坏全局变量）。

## 五、安装包设计

### 5.1 形态
单个 EXE，**载荷追加在自身尾部**，尾部 400 字节清单记录每个文件的偏移与长度：

```
[setup.exe 247KB][datapack.hvp 845MB][d3d9.dll][dinput8.dll][main.patch][Footer]
```

安装器运行时读自己的尾部清单 → 按偏移复制文件。无需任何解压库。

### 5.2 界面功能
- **免责声明 + 使用前必读 + 鸣谢 + 转载说明 + 已知限制**（可滚动文本框）
- **游戏目录**：自动从注册表定位 Steam 路径（`HKCU\Software\Valve\Steam`），可手动改 / 浏览
- **「安装前备份原文件」**（默认勾选）：把 `datapack.hvp` 备份为 `datapack.hvp.o2bak`
- **「同时安装宽屏补丁」**（默认勾选）
- 进度条 + 状态提示 + 完成后弹窗
- **「还原原版」**按钮：删补丁 DLL、从备份恢复数据包；无备份时提示用 Steam 校验

### 5.3 验证
- 载荷逐项 md5 回读校验 ✓
- **端到端自测**（`setup.exe /test:<目录>` 静默安装）：ExitCode=0，四个文件 md5 全对，备份正确 ✓
- 窗口启动冒烟测试：标题正确 ✓
