### 翻译时的硬性规范

| 类型 | 规范 |
|---|---|
| **UI 按钮 / 菜单项** | **绝对不加 `\n`**（引擎按单行排版，换行会截断显示） |
| **长对话 / 文档** | 每行 ≤ 24 汉字（470px），优先在标点处断；可交给 `rewrap8.py` 自动处理 |
| **`%s` `%d`** | 原样保留，顺序不可变 |
| **`<PS2_CROSS>` 等标签** | 原样保留，一个字符都不能动 |
| **换行符** | 只允许 `\n`；不得出现 `\r`、`\t` 或其它控制字符（`body_safe` 会拒绝） |
| **语料列结构** | 9 列，行序必须与容器记录一一对应（`ta2_write` 会断言） |

### 自动断行脚本
`_verify/rewrap8.py`：读 `full4` → 只对超宽条目断行 → 输出新语料。
内置规则：英文/数字原子、标点优先、高频双字词保护（语料自统计 bigram）、结构助词不落行首、保留 `\n\n`。
