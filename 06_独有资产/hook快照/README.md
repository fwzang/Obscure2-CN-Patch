# hook快照 · 历史版本归档

## 重要：这里**不是**发布版

本目录是开发过程中每个版本 DLL 的**留档**（v21 → v49，以及早期的 vA / vB 变体），
用于回溯"某一版到底改了什么"。**不要从这里取 DLL 给玩家用。**

**当前发布版在：**

| 方案 | 路径 | md5 |
|---|---|---|
| 方案 B（活楷） | `01_安装包/手动安装版/d3d9.dll` | `6326d10ca1d7c760becc1c4b6e0442a8` |
| 方案 A（端黑） | `01_安装包/手动安装版/方案A_寒蝉端黑体/d3d9.dll` | `d0295c8726721c20274ae8a8dc13b109` |

两者都是 v69 构建（`V69_PROD` 标记），区别只在字体图集。

## 版本线索

| 文件 | 说明 |
|---|---|
| `d3d9_v21_fallback.dll` | v21 备胎版（早期回滚点） |
| `d3d9_v28_blacklist.dll` | v28 黑名单实验版 |
| `d3d9_v30` ~ `d3d9_v49` | 逐版迭代留档 |
| `d3d9_v47_installed.dll` | v47 装机现场抓取的那一份 |
| `d3d9_v49.dll` | V1.01/V1.02 发布时使用的基线（`47060c4b`） |
| `d3d9_vA.dll` / `d3d9_vB.dll` | 早期方案 A/B 变体（**非当前版本**） |

> 判断任意 DLL 属于哪一版：搜二进制里的 `Vxx_PROD` / `Vxx_DIAG` 标记，
> 或看 `d3d9proxy.log` 首行。只看文件名会被 `d3d9_vA.dll` 这种命名骗到。
