【V1.04 更新内容】（终版）

★ 核心：「D3D9On12 自动分流」——解决 NVIDIA 显卡高分辨率下提示贴图不显示，
   并附带修复电击枪 / 电击器的冻结与崩溃

1.【N 卡自动转译】启动时自动读取显卡厂商 ID：
   · NVIDIA（0x10DE）→ 自动改走微软官方 Direct3D9On12（D3D9 经 D3D12 后端渲染），
     绕开 N 卡 D3D9 驱动对越界顶点的严格裁剪，浴室等场景的提示贴图恢复正常显示；
   · AMD / Intel / 其它 → 保持原生 DX9 路径，不做任何干预（A 卡本来就正常）。
   玩家无需设置任何东西，装上即生效，从 Steam 启动同样有效。

2.【附带修复 · 电击枪】启用 D3D9On12 后，电击枪 / 电击器的冻结与崩溃问题一并解决
   （该项是 N 卡原生 D3D9 路径下的已知 bug）。已实机验证：可正常使用电击枪。

3.【安装时可选渲染模式】本安装器提供两档（写入游戏目录 o2_mode.txt，从 Steam 启动同样生效）：
   · 智能兼容（推荐）：自动检测显卡厂商 —— 仅 NVIDIA(0x10DE) 启用 On12 修复，
     AMD(0x1002) / Intel(0x8086) 一律保持原生 DX9（A 卡本来就正常，不做任何干预）；
   · 强制原生：所有显卡都走原生 DX9（N 卡高分辨率下的提示贴图可能复现缺失）。
   优先级：环境变量 > o2_mode.txt > 智能分流。
   · set O2_FORCE_ON12=0   临时强制原生（覆盖安装时选择）
   · set O2_FORCE_ON12=1   临时强制 On12
   · set O2_NO_FLASHFIX=1  关闭启动阶段的渲染保护窗口（极少需要）
   代理在 On12 创建失败（老系统无 D3D12 / 驱动不支持）时会自动回落原生路径。

4.【坐标篡改彻底退役】此前试过"读顶点改坐标"的补救方案，实测在 On12 下会触发
   2907 次误改（y×0.75），导致文字变横线、UI 底框拉扯。V1.04 已永久关闭该机制
   （代码保留但不执行，O2_V79=1 仅供技术取证，正常游玩不要开）。

5.【继承】V1.03.3 的分辨率自适应、字体提升阈值 9（贴图不被误杀）、
   V1.03.2 的 stage0 门槛与严格字体判定、V1.02 的窗口化防卡死、
   V1.01 的双字体方案选择，全部保留。

【已知限制 · Steam 游戏内覆盖层】
本补丁为修复 N 卡贴图缺失，默认启用 D3D9On12 转译（把 D3D9 交给 D3D12 后端渲染）。
该模式下 Steam 游戏内覆盖层（Overlay / Shift+Tab 面板）无法显示。
· 需要覆盖层的玩家：把游戏目录 o2_mode.txt 里的 auto 改成 compat，即可恢复覆盖层，
  但 N 卡高分辨率下的提示贴图缺失会重现。
· A 卡 / Intel 用户：默认原生 DX9，覆盖层不受影响。
· 覆盖层缺失不影响成就解锁、时长统计、云存档同步与汉化文本显示。
